# Inventario-Tecnologico
Sistema Full-Stack (FastAPI, Vue 3, PostgreSQL, Docker) para la gestión centralizada de Bienes Nacionales de la Coordinación de Telemática de Fundacite Sucre. Incluye control de acceso basado en roles (RBAC/JWT), auditoría inmutable de equipos mediante Triggers/JSONB, y diseño relacional optimizado para inventario de hardware heterogéneo.
